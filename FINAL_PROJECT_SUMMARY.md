# Мой финальный проект автоматизации

## Выбранная область - Банковские операции
Я выбрала банковские операции, так как это основные бизнес-процессы 
в приложении Mini Bank для пользователей.
В тестах проверяется создание счетов через API и UI и несколько видов переводов.

## Созданные тесты
1. test_api_create_accounts_different_roles - Параметризированный API тест, в котором создаются счета SAVINGS и CHECKING под всеми ролями.
2. test_create_account_by_user - Параметризированный UI тест создания счёта SAVINGS и CHECKING с проверкой отображения информации о счёте на странице.
3. test_new_account_visible_in_transfers - Параметризированный UI тест с подготовкой данных через API создания счёта двух типов и отображение его в выпадающих списках на странице Transfers. Под ролью USER. 
4. test_external_transfer_checking - UI тест с подготовкой данных через API. Перевод между пользователями с CHECKING на CHECKING и проверкой балансов.
5. test_external_transfer_savings_checking - Тест перевода между пользователями с SAVINGS на CHECKING. Перевод 500 единиц - верхняя граница дневного лимита + комиссия
6. test_transfer_exceeding_daily_limit - Негативный тест попытки перевода между пользователями с превышением дневного лимита.
7. test_two_external_transfers - Тест двух внешних переводов подряд.
